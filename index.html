How this works. The score (every Pbind, its repeat counts and the Ptpar entry times) is read straight from Tett_A_In_C.scd when the page loads. The SynthDefs are compiled from the same file into .scsyndef files and run on SuperSonic, which is SuperCollider's own synthesis server compiled to WebAssembly. Nothing is streamed: every sound is synthesized on this computer.

For a screen share, tick Share sound in Zoom so the class can hear it. SynthDefs: pluck after John Drumheller's Karplus-Strong example; star from sccode.org/1-522. Visuals in p5.js.
